# Synesthia 1.2.2

A maintenance release. Switching audio sources is more reliable, an unplugged audio interface no longer leaves the canvas frozen, and the direct-download build gives clearer messages when it can't control Music or Spotify. Requirements and permissions are the same as 1.2.1.

## Improved

- **Smaller update downloads** — updates can now arrive as a small patch instead of the full disk image. 1.2 was offered the patch but couldn't download it, so Sparkle quietly downloaded the whole app instead. The fix is on the server, so copies already installed benefit without changing anything.
- **Clearer player-control messages** (direct download) — if Music or Spotify isn't running, Synesthia now says so instead of sending you to the Automation settings for a permission you already granted. Only a real refusal turns player control off. A refusal from one player is no longer forgotten after a successful command to the other.

## Fixed

- **Unplugging an audio interface** — if the input device you're listening to disappears, Synesthia now stops listening and says so with a banner. Before, it kept claiming to listen: the display stayed awake and the canvas sat frozen. The device picker also drops the missing device, so ⌘L no longer opens the default microphone without telling you.
- **Visuals after leaving the demo track or a file** — a paused file kept sending silence into the analysis alongside the new source. It now goes fully quiet when you switch away.
- **Switching sources while one is still starting** — changing source while system audio was still connecting could make the retry act on the new source, for example by triggering a microphone prompt you didn't ask for. A source that finishes starting after you've switched away now stops, and its errors no longer show up against the source you picked.
- **Banners that outlived the problem** — an error banner now clears once audio input starts successfully. Switching to a file that can no longer be opened now shows the error instead of leaving a silent canvas.
- **Reduce Motion when changing visualizers** — with Reduce Motion on, a new visualizer could fade in at the previous one's brightness. It now starts fresh.
