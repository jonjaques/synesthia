# Synesthia 1.2.1

A maintenance release. It fixes the update failure that hit 1.2 in the direct-download build, fixes an app that could relaunch into nothing but its Settings window, and reworks first launch so the demo track starts when you ask for it rather than playing underneath the welcome sheet.

## New

- **Window ▸ Synesthia (⌘0)** — a named way back to the canvas if you've closed its window. Previously File ▸ New Window was the only route, which reads as "make a second one" rather than "show me the app again".
- **Demo track transport in the source menu** — Play/Pause Demo Track now appears alongside the audio sources, so stopping the loop isn't a hunt. The Playback menu and the ⌘L shortcut say the same thing.

## Improved

- **First launch is quiet until you answer the welcome sheet** — nothing plays behind it. **Continue** grants no permission and starts the bundled demo; picking a source goes straight to that source. The sheet now says so before you click.
- **Play/pause button matches the source** — the demo track and a file you've opened get play/pause icons and tooltips; system audio and input devices keep the listening waveform. It used to offer "Stop listening" for a track the app was playing itself.

## Fixed

- **Updates failing to download** — direct-download copies of 1.2 could report "An error occurred while downloading the update" indefinitely, even though the new version was published and correctly signed: a stale "not found" answer was being cached at the edge for hours. Update and download URLs now refuse to be cached when they fail. This is the reason to install 1.2.1 by hand if 1.2's updater never got you here.
- **Relaunching into a stranded Settings window** — quitting while the visualizer window happened to be closed could bring the app back with only Settings showing, and clicking the Dock icon opened a second Settings window instead of the canvas. The canvas is now the window the app opens, and the state doesn't stick.
- **Choosing the source you were already on** — selecting a source from the welcome sheet that matched the current one could dismiss onto a silent canvas. It now starts.
